스마일일렉 홈페이지 — 배포 및 검색등록 가이드
==========================================

[0] 먼저 실제 정보로 바꾸기
  build_site.py 맨 위 CONFIG에서 아래 항목을 실제 정보로 바꾼 뒤 다시 생성합니다.
  (직접 하기 어려우시면 정보만 알려주시면 다시 만들어 드립니다.)
  - 상호, 대표 전화, 사업장 주소, 사업자등록번호, 대표자명, 영업시간
  - 도메인 주소 (아래 1단계에서 구입한 주소)
  ※ 상호·전화·주소는 홈페이지, 네이버 플레이스, 블로그 모두 "완전히 똑같이" 적어야 검색 신뢰도가 올라갑니다.

[1] 도메인 구입 (홈페이지 주소)
  - 가비아, 카페24, 후이즈 등에서 구입합니다.
  - 추천 형태: 영문 상호 + .co.kr 또는 .com  (예: smile-elec.co.kr)
  - 짧고 전화로 불러주기 쉬운 주소가 좋습니다.

[2] 호스팅 (홈페이지 올리는 곳) — 무료 방법 추천
  ▶ Netlify (가장 쉬움)
    1) netlify.com 가입
    2) "Deploy manually" 화면에 site 폴더를 통째로 끌어다 놓기 → 바로 공개됨
    3) Domain settings → Add custom domain 에 구입한 도메인 입력
    4) 도메인 구입처(가비아 등)의 DNS 설정에 Netlify가 알려주는 값을 입력
    5) HTTPS(보안 연결)는 자동으로 켜집니다.
  ▶ 다른 선택지: Cloudflare Pages(무료), 카페24 웹호스팅(유료, 한국어 고객센터)
  ※ 수정할 때는 파일을 고친 뒤 site 폴더를 다시 끌어다 놓으면 됩니다.

[3] 네이버 서치어드바이저 등록 (네이버 검색 노출의 시작)
  1) searchadvisor.naver.com 접속 → 네이버 로그인 → 웹마스터 도구
  2) 사이트 등록에 도메인 입력 → "HTML 태그" 방식 선택
  3) 나오는 인증코드(content="..." 안의 값)를 CONFIG의 naver_verify 에 넣고 다시 생성·업로드 → 소유 확인
  4) 요청 → 사이트맵 제출: https://내도메인/sitemap.xml
  5) 요청 → RSS 제출: https://내도메인/rss.xml
  6) 요청 → 웹 페이지 수집: 메인과 지역 페이지 주소를 하나씩 수집 요청

[4] 구글 서치콘솔 등록
  1) search.google.com/search-console → 속성 추가 → URL 접두어에 도메인 입력
  2) "HTML 태그" 방식 → 인증코드를 CONFIG의 google_verify 에 넣고 다시 업로드
  3) Sitemaps 메뉴에 sitemap.xml 제출

[5] ★ 지역 검색에서 가장 중요한 것: 지도 등록
  "의정부 전기수리" 같은 검색은 지도(플레이스) 결과가 맨 위에 나옵니다.
  - 네이버 스마트플레이스(smartplace.naver.com)에 업체 등록
    · 업종: 전기공사 / 전기수리
    · 홈페이지 주소, 블로그 주소 연결
    · 서비스 지역, 현장 사진, 영업시간 입력
  - 구글 비즈니스 프로필(business.google.com)도 같은 정보로 등록
  - 고객 리뷰는 실제 고객에게 정중히 부탁드리세요. (가짜 리뷰는 제재 대상입니다)

[6] 노출을 키우는 운영 팁
  - 네이버 블로그 시공 후기 글 끝에 홈페이지 해당 지역 페이지 링크를 넣기
    (예: 의정부 현장 글 → https://내도메인/uijeongbu.html)
  - 홈페이지 지역·서비스 페이지에 실제 현장 사진 추가 (원하시면 사진 넣는 칸을 만들어 드립니다)
  - 등록 후 노출까지 보통 수 주 ~ 수 개월 걸립니다. 꾸준함이 핵심입니다.
